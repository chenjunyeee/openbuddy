# OpenBuddy · 开在桌面上的小搭档

有时候你对着屏幕太久，桌面太安静，光标像在独舞——于是我们做了一个 **桌宠**：它不抢戏，但一直在。

OpenBuddy 是一只（或一群）住在电脑角落里的 **小同伴**。它可以趴在你顺手看一眼的位置，用自己的节奏动弹、犯傻、陪你熬过枯燥的会话。你不必把它当成工具；它更像总在边上的那只小动物：**有脾气、有存在感，偶尔还会和你聊两句**。

我们喜欢这个 idea：**工作可以是严肃的，但桌面可以偷偷温柔一点。**  
它不是用来拯救生产力的神话，而是给日常补一点趣味——像窗边多了一盆会动的小东西。

如果你也曾怀念早年那些会乱跑、会碎嘴、会不讲道理只占位置的桌宠时代，那大概懂得我们在玩什么：**一点陪伴感，一点随机，一点属于自己的小剧场。**

欢迎把它当作你的 **桌面室友**——不用正经介绍，合眼缘就好。
